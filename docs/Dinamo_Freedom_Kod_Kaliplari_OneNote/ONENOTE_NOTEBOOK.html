01 · Genel kurallar

Goto yok. GoTo, On Error Goto kullanma. Akış: If / Exit Sub. Hata: On Error Resume Next + Err.Number / Err.Clear.
On Error Resume Next
' ... riskli çağrı ...
If Err.Number <> 0 Then
	Err.Clear
	Exit Sub
End If

Oracle: doğrudan bağlanma / yazma yok. Makro XML içinde SELECT / RunSqlQuery OK (kullanıcı import eder).

Örnek klasör: C:\KOD_ARA_KLASÖRÜ — yeni özellik öncesi benzer örnek ara.

Parçalı kod: SRNUM. UAPP10T2’de FORMKODU yok. RWSTDF anahtar: ITEMCODE.

03 · Grid doldurma

Doğru: RunSqlQuery → Empty → CopyTable → SetCurrentRow → Refresh
Set TblDolu = Doc.RunSqlQuery("TABLO_DOLU", SQL)
TrnTable.Empty
TrnTable.CopyTable(TblDolu)
TrnTable.SetCurrentRow 1
TrnTable.Refresh
Set XDOLU = Doc.RunSQLQuery("X_DOLU", sql)
Set X = Doc.GetTableObject("X")
X.Empty
If XDOLU.GetRecCount > 0 Then
	X.CopyTable(XDOLU)
	Set XDOLU = Nothing
	X.SetCurrentRow 1
End If

Ek satır:

Tbl.AddRow
Tbl.SetCurrentRow Tbl.RowCount
Tbl.OZELLIK = sOzellik
Tbl.SEC = "H"
Sadece Create* + AddRow ile doldurmak → grid boş kalır.

06 · SQL kalıpları

Makro SQL’de WITH (CTE) yok. EXISTS / alt sorgu / UNION kullan. WITH (NOLOCK) tablo hint’i CTE değildir — OK.
sql = "SELECT Durum, COUNT(*) AS PersonelSayisi FROM (" & vbCrLf
sql = sql & "    SELECT ... FROM dbo.TABLO p WITH (NOLOCK) ..." & vbCrLf
sql = sql & ") x WHERE x.rn = 1 GROUP BY x.Durum"
' Turkish_BIN benzeri
sql = sql & " AND UPPER(kolon) LIKE '%KELIME%'"
Set TblGk = Doc.Select1("vygk18", "STOK00", "KOD='" & Replace(sKod, "'", "''") & "'", "", -1)

GRID D= alanları = SQL kolon alias’ları (birebir).

	Err.Clear

End If
